How to Publish New Research Documents (Netlify Static Architecture)

Because NITHESH.DEV is a zero-backend static platform hosted on Netlify, browser file inputs do not permanently write to the server. To publish new PDFs, notes, or diagrams permanently:

  1. Place your PDF paper in research/papers/, markdown/HTML notes in research/notes/, or diagrams in research/diagrams/.
  2. Open data/research.json in VS Code and append a new JSON entry referencing the file path.
  3. Run git add . && git commit -m "Add research paper" && git push. Netlify will automatically deploy the updated library.
