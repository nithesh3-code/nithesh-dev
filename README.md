## 1. Platform Overview

**NITHESH.DEV** is a modular, zero-backend personal engineering website, AI/ML systems portfolio, independent research laboratory, and programming language documentation hub built with **HTML5, CSS3, and Vanilla JavaScript**.

It combines six core functions into one cohesive engineering platform:
1. **Professional ATS-Friendly Digital Resume** (`resume.html`)
2. **Software Engineering Portfolio** (`projects.html` & `project-detail.html`)
3. **AI/ML Project Showcase** (`projects.html` & `ai-systems.html`)
4. **Independent Research Laboratory** (`research.html`)
5. **Programming Language Development Documentation — Frisian / Farisan** (`language-development.html`)
6. **Technical Knowledge & Experiment Archive** (`ai-systems.html` & `skills.html`)
